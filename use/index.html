我正在使用

硬體

  • MacBook Air M1 主力機，目前找不到二手萬元上下、續航佳，能夠上一整天課不插電的電腦了。
  • ThinkPad X230 可裝 Linux, Win 的備用機，有 USB 3.0，已改裝 X220 鍵盤。
  • Pixel 6 顏色好看、可刷機
  • Z Flip 4 漂亮的摺疊機

軟體

  • Linux (KUbuntu, XUbuntu) 可體驗自由作業系統的美好： 沒有間諜軟體、沒有煩人的更新、沒有煩人的登入帳號、不會在背後做圖利某些公司的事、沒有型號限制，不會說太舊不能裝 這世界不是只有 Win/Mac 可用欸！打開電腦作業系統的選擇權！
    • 為什麼你該試試 Linux (撰寫中)
  • GrapheneOS 可把 Google play service 從系統程式降級成普通 App，同時又可用推播、定位、登入驗證等功能。但鬧鐘 App 有夠醜、又超難聽。另外台灣行動支付不能用。
  • macOS 介面越來越無趣，有些工具只能開發 Apple 產品，但是軟體相容度比較好 (Word, Line …)，為了搭配 Macbook 被迫使用，好處是省事。
  • Brave 內建擋廣告的瀏覽器
    • Vimium 完全使用鍵盤瀏覽網頁，免滑鼠非常省力！
  • 終端機相關
    • Ranger 用上下左右進入目錄，告別 ls, cd
    • Tmux 畫面分割工具
    • zsh 可裝比較多擴充插件的 Shell
    • Vim 文字編輯器
    • cmus 可用終端機聽歌
    • lazygit 視覺化 git
  • Obsidian 擴充插件：
    • Excalidraw 非常容易上手的繪圖工具
    • Hugo Publish 一鍵轉成部落格可用的 MarkDown 格式
  • VSCode
    • Continue 可接便宜的 API 使用 AI Agent 寫程式、與電腦互動
