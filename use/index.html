軟體 - 作業系統

  • Linux (KUbuntu, XUbuntu) 可體驗自由作業系統的美好：沒有間諜軟體、沒有煩人的更新、沒有煩人的登入帳號、不會在背後做圖利某些公司的事、沒有型號限制，不會說太舊不能裝。 這世界不是只有 Win/Mac 可用欸！打開電腦作業系統的選擇權！
    • 為什麼你該試試 Linux (撰寫中)
    • 讓 Linux 日常使用需要的步驟 [[裝新系統 設定好 Linux]]
    • 這是我常用的設定 [[裝新系統 個人設定]]
  • GrapheneOS
    • ✅ 可把 Google play service 從系統程式降級成普通 app
    • ✅ 同時又可用推播、定位、登入驗證等功能。
    • ❌ 內建 App 較陽春。
    • ❌ 台灣行動支付不能用。
  • macOS （準備換掉）
    • ✅ 軟體相容度比較好 (Word, Line …) It just works.
    • ❌ 介面越來越無趣
    • ❌ 有些工具只能開發 Apple 產品
    • ❌ KDE connect, android transfer 總是不能用，被鎖死在 Apple 生態圈。
    • ❌ macOS 不讓你裝軟體
    • ❌ 為了搭配 Macbook 被迫使用，準備換成 Asahi Linux

軟體 - GUI

  • Brave Origin 內建擋廣告的瀏覽器
    • Vimium 完全使用鍵盤瀏覽網頁，免滑鼠非常省力！需要調整：[[如何自訂 Brave 開啟的新分頁]]
  • Obsidian 擴充插件：
    • Excalidraw 非常容易上手的繪圖工具
    • Hugo Publish 一鍵轉成部落格可用的 MarkDown 格式
  • VSCode
    • Continue 可接便宜的 API 使用 AI Agent 寫程式、與電腦互動

  • zsh 可裝比較多擴充插件的 Shell
  • Vim 文字編輯器
  • cmus 可用終端機聽歌
  • lazygit 視覺化 git
  • tldr 比 man 好用的指令提示器 (pipx)
  • hugo blog 產生器
  • wlcopy 複製終端機標準輸出的工具
