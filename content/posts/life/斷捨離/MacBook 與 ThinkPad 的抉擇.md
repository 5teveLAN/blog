我目前有兩台主力用筆電，MacBook Air M1 (8/256) 和 ThinkPad T490。因為每次換機都要考量到資料同步問題，很難放心無縫銜接使用，所以我習慣只用一台，另一台會注定要吃灰。

**我已經決定放棄所有 MacBook 的好，留下信仰機 ThinkPad。** 以下表格說明我為什麼放棄 MacBook 的高效能、做工，以及如何克服 ThinkPad 的缺點：

### 1. 效能

| **功能**       | **MacBook**         | **ThinkPad**      | **評論 / 折衷辦法**                        |
| ------------ | ------------------- | ----------------- | ------------------------------------ |
| **效能 (CPU)** | 👑 CPU 超快，且不插電時全速運行 | CPU 堪用，不插電時比較 Lag | 筆電文書用，需要高性能時使用桌機                     |
| **效能 (RAM)** | 只有 8G RAM，絕對不夠！     | 👑 RAM 用不完        | 我用的 App 都超級吃 RAM。8G 連開個小 App 都需要提心吊膽 |
| **硬碟**       | 只有 256G，難以安裝虛擬機     | 👑 有 1T，可以安裝虛擬機   | 在非常時期可能會需要安裝 Windows 來用，會佔大量空間       |
| **電池**       | 👑 續航無敵             | 續航普通              | 為了延長電池壽命，我大多時間都是插著電源                 |
| **風扇**       | 👑 無風扇              | 有風扇               | 噪音我沒差，且冬天可當暖氣                        |

### 2. 外觀與螢幕

| **功能**        | **MacBook**     | **ThinkPad**          | **評論 / 折衷辦法**                               |
| ------------- | --------------- | --------------------- | ------------------------------------------- |
| **外觀、重量與耐用度** | 👑 重量輕、外觀薄、金屬抗刮 | 塑膠不耐刮                 | Thinkpad 當作練健身                              |
| **喇叭**        | 👑 超好           | 超爛                    | 很少聽。可用外接喇叭解決, 朋友有閒置喇叭。                      |
| **螢幕**        | 👑 超好           | 超爛                    | Thinkpad 也可以改裝便宜 LCD, CP質高。原本的螢幕 DIY 成外接螢幕。 |
| **單手開螢幕**     | 👑 可            | 不可                    | 反正一天也只會開兩三次                                 |
| **螢幕角度**      | 有限制             | 👑 可 180 度翻轉，提供更多好玩角度 | -                                           |
| **外觀**        | 果粉樣             | 👑 極客樣                | 風格不同，我更喜歡全黑的筆電。                             |

### 3. 周邊與擴充

| **功能**    | **MacBook**                    | **ThinkPad**                             | **評論 / 折衷辦法** |
| --------- | ------------------------------ | ---------------------------------------- | ------------- |
| **插槽**    | 只有兩個 USB-C，音源孔。需要透過轉接卡，破壞一體性。  | 👑 擴充槽齊全，(還有 USB3, HDMI, microSD, RJ45)。 | -             |
| **維修與改裝** | 零件嬌滴滴，難拆解，難以找到便宜高品質備料。         | 👑 零件好更換，便宜，拆裝方便，DIY 樂趣多                 | -             |
| **鍵盤**    | 鍵盤清脆，但是長時間比較不耐打                | 👑 鍵盤比較爽                                 | -             |
| **觸控板**   | Asahi Linux 的觸控板在打字時容易誤觸，懶得調整。 | 👑 因為有小紅點，所以可以關閉觸控板                      | -             |

既然 ThinkPad 的缺點全部都可以克服，且 MacBook 又有難以使用的情況，最終決定留下 ThinkPad。**這樣做也是在實踐我不追求新產品、持續使用堪用硬體的環保理念。**
